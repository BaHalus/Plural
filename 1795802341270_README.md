# Formatos GCS — análise técnica e importador de referência

Material produzido em 27/11/2026 durante a calibração do importador previsto para a **v0.7.2** do kit Singular. Cobre os formatos de arquivo do ecossistema GCS usados neste acervo (`.gct`, `.gcs`, `.gcs.txt`) e entrega um importador de referência em Python, validado contra amostras reais.

## 📁 Conteúdo desta pasta

| Arquivo | O que é |
|---|---|
| `Analise_formato_GCT.md` | Especificação completa: gramática recursiva, campos, enums, glossário PT↔EN, janelas de versão, decisões de design e as recomendações R1–R24 para o importador |
| `importador_gct.py` | Implementação de referência (Python 3.9+, só stdlib) — converte templates `.gct` (fase 1) e fichas `.gcs`/`.gcs.txt` (fase 2), com selftest embutido |
| `catalogo_amostras_adicionais.csv` | Ficha técnica das amostras adicionais (versão, tipo-raiz, pontos, contagens) |

## ⚡ Uso rápido

```bash
# importa qualquer combinação de arquivos/pastas/zip:
python3 importador_gct.py <entrada> [...] --out resultado

# roda as duas suítes de auto-teste (deve sair tudo PASS):
python3 importador_gct.py fixtures_importador_gcs_v1.zip --selftest
```

Saídas: `relatorio_importacao.md` (visão geral, por arquivo, avisos agrupados) e `canonicos/*.json` (um JSON normalizado por entrada, com cópia crua preservada para auditoria).
